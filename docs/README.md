# docs/ — руководства ОС ДИСПАК и справочники терминала

Собрано в одном месте, чтобы ИИ-агент и человек искали сведения здесь, а не
в исходниках и не экспериментом на живой машине.

## Правило нулевого шага

**Появилась диагностика неисправности или нужно выполнить приказ ОС — сначала
читаем руководство, потом пробуем на машине.** Приказ может выполнить не то
(например `СБО` без параметров исключает все устройства вывода из
конфигурации), а сообщение может значить не то, что кажется по его тексту.
