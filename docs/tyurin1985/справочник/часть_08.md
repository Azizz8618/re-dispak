### 8.1. Заказ областей в паспорте задачи

Заказ областей в паспорте реализует три функции: к моменту выбора задачи все заказанные области переносятся на установленные первичные тома; пользователь задаёт виртуальный номер, позволяющий менять имя области только в паспорте; можно разрешить или запретить запись в область (`tyurin1985-full.txt:17556`-`tyurin1985-full.txt:17573`; OCR: `ocr/page-0293.txt:1`-`ocr/page-0293.txt:7`).

ТЕСТ. МАССИВ1`) и представлены в каталогах архива древовидной структурой (`tyurin1985-full.txt:17575`-`tyurin1985-full.txt:17583`; OCR `ocr/page-0293.txt:9`-`ocr/page-0293.txt:17`). ### 8.3. Вызов сервиса ARFA и формат директив

Диалоговая программа ARFA (`Ага` в OCR) предоставляет все средства создания/уничтожения областей, управления доступом и административные функции; все операции уровня экстракодов доступны и через неё (`tyurin1985-full.txt:17623`-`tyurin1985-full.txt:17633`). Вызов: набрать на терминале 6- или 12-значный шифр ОС Диспак (`tyurin1985-full.txt:17635`-`tyurin1985-full.txt:17636`; OCR `ocr/page-0293.txt:69`-`ocr/page-0293.txt:70`). После входа в решение терминал выдаёт приветствие `*** Ага / ВЕРСИЯ ОТ ХХ.ХХ.ХХ` и приглашение `=` (`tyurin1985-full.txt:17640`-`tyurin1985-full.txt:17646`; ⚠ OCR НЕ ПОДТВЕРЖДЕНО: `жж Ага`).

Форматы директив (`tyurin1985-full.txt:17647`-`tyurin1985-full.txt:17665`):

```
<ИД. ДИРЕКТИВЫ> [<ИМЯ ОБЛАСТИ>][:<СПИСОК ПАРАМЕТРОВ>]
<ИД. ДИРЕКТИВЫ> [<СПИСОК ПАРАМЕТРОВ>]
```

Идентификатор распознаётся по первым трём буквам; параметр имеет вид `<КЛЮЧ>=<ЗНАЧЕНИЕ>`; параметры разделяются запятыми, ключ распознаётся по первому символу, порядок произволен; параметры с нулевыми значениями можно не задавать, при отсутствии параметров двоеточие опускается.

Управляющие директивы (`tyurin1985-full.txt:17667`-`tyurin1985-full.txt:17673`): `КОНЕЦ` - окончание работы; `ПЕЧ` - печать протокола на АЦПУ (повтор отменяет); `ЭКР` - выдача ответов на терминал; `ЭХО` - повторение принятых текстов на экране; `///` - секретный приём.

Для мониторной системы Дубна (`tyurin1985-full.txt:17675`-`tyurin1985-full.txt:17689`): в пакет включается карта `#CALL АВЕА` (OCR, по руководству 1988 - `#CALL ARFA`) после карты заказа библиотеки; каждая директива на отдельной перфокарте с первой позиции, за директивами - карта `КОНЕЦ`; всё печатается на АЦПУ; для отмены печати в позиции 1-6 карты пишется `БЕЗПЧ:`. ⚠ OCR НЕ ПОДТВЕРЖДЕНО: `АВЕА`, `SPOrDeion Ага` (`tyurin1985-full.txt:17684`).

Общее правило диагностики (`tyurin1985-full.txt:17691`-`tyurin1985-full.txt:17705`): для каждой директивы приводятся описание, диагностические сообщения и авостные ситуации; одинаковые параметры описываются только в первой директиве; одни и те же ошибки могут дать и сообщение, и авост (обычно `НЕТ ПОЛНОМОЧИЙ` и авост `ЧУЖАЯ ИНФОРМАЦИЯ`) в зависимости от режима регистрации несанкционированного доступа, заданного администратором для группы.

#### 8.4.4. Задание прав доступа

`ПРАВА [<ИМЯ ОБЛАСТИ>]:[N=<ВИРТУАЛЬНЫЙ НОМЕР>,][П=<ПАРОЛЬ ЗАПИСИ>,][Ш=<ШИФР>,]Р=<РАЗРЕШЕННЫЕ ДЕЙСТВИЯ>` (`tyurin1985-full.txt:17923`-`tyurin1985-full.txt:17929`; ⚠ OCR НЕ ПОДТВЕРЖДЕНО: `ess РИЕТУАЛЕНЫЙ`, `Ш = <ШИФР>`).

Задаётся либо имя, либо виртуальный номер; если есть пароль записи, он указывается; шифр - шестизначное десятичное число, любая цифра может быть заменена точкой (`tyurin1985-full.txt:17930`-`tyurin1985-full.txt:17938`). Права (`tyurin1985-full.txt:17940`-`tyurin1985-full.txt:17950`): `НЕТ` - доступ запрещён и шифр выбрасывается из списка; `ЧТЕНИЕ` - чтение после подтверждения пароля чтения; `ЗАПИСЬ` - чтение и запись после подтверждения паролей; `МОНОПОЛЬНО` - то же плюс монопольный режим. #### 8.4.6. Запрос списка допущенных лиц (КТО)

`КТО [<ИМЯ ОБЛАСТИ>]:[\=<ВИРТУАЛЬНЫЙ НОМЕР>,][П=<ПАРОЛЬ ЧТЕНИЯ>]` (`tyurin1985-full.txt:18051`-`tyurin1985-full.txt:18054`). Задаётся имя или номер; если есть пароль чтения, он указывается (`tyurin1985-full.txt:18056`-`tyurin1985-full.txt:18058`). Ответ (`tyurin1985-full.txt:18060`-`tyurin1985-full.txt:18075`):

```

...
ПРОЧИЕ <ПРАВА ПРОЧИХ>
```

Права: `МОНОП.` - монопольный доступ, `ЧТ/ЗП` - чтение и запись, `ЧТ` - только чтение, `НЕТ` - доступ запрещён. Порядок проверки: шифр хозяина, затем шифры списка в порядке выдачи КТО, затем «все прочие»; ПРАВА заносят шифры сверху вниз; пример с `5213..` (запись) и `52....` (только чтение) показывает, что порядок задания определяет итог; при выбросе шифров образуются «дырки», которые заполняются первыми (`tyurin1985-full.txt:18077`-`tyurin1985-full.txt:18097`). Только хозяин (`tyurin1985-full.txt:18099`).

Диагностика (`tyurin1985-full.txt:18101`-`tyurin1985-full.txt:18123`): `НЕВЕРНОЕ ИМЯ ОБЛ.`, `ОШИБКА В ШИФРЕ`, `ТАКОГО ИМЕНИ НЕТ`, `НЕТ ПОЛНОМОЧИЙ`, `ОБЛАСТЫКАТАЛОГ`, `НЕ ЗАДАН ПАРОЛЬ`. Авосты (`tyurin1985-full.txt:18125`-`tyurin1985-full.txt:18137`): `ЗАПРЕЩ. НАПР. В ЭК`, `ОБРАЩ. К НЕЗАК. МЛ`, `ЧУЖАЯ ИНФОРМАЦИЯ`, `НЕВЕРНЫЙ ПАРОЛЬ`.

### 8.5. Прохождение архивных задач

При вводе (формировании) задачи идёт синтаксический контроль имён; без ошибок задача поступает во входную очередь; для задач с разделами ТЕЛЕ или ЖДЕМ обработка откладывается до готовности к выборке (вызов с терминала, нормальное окончание ожидаемой задачи или время из ЖДЕМ); остальные идут на обработку к архивной системе, где проверяется существование заказанных областей (`tyurin1985-full.txt:18236`-`tyurin1985-full.txt:18251`). Это полностью совпадает с `Dispak-programmer-guide.md:1516`-`Dispak-programmer-guide.md:1523`.

| Ситуация | Диагностика | Строки |
|---|---|---|
| Заказана область-каталог или несуществующая область | `НЕТ ОБЛАСТИ <ИМЯ>` + `<ШИФР> ВЫБР` (OCR `ОГЧЕЗКЗАДАВА ВЫБР`) | `tyurin1985-full.txt:18252`-`tyurin1985-full.txt:18259`. ⚠ OCR НЕ ПОДТВЕРЖДЕНО |
| Нет права работать с областью, либо область заказана на запись при праве только на чтение | `НЕСАНКЦИОНИРОВАННЫЙ ДОСТУП <ИМЯ>` + `<ШИФР> ВЫБР` | `tyurin1985-full.txt:18260`-`tyurin1985-full.txt:18270` |
| Обработка архивной системой отложена | В ответе на директиву СКВ - `ЗАПР. АРХ.` | `tyurin1985-full.txt:18272`-`tyurin1985-full.txt:18275` |
| Область на неустановленном томе, вытолкнута на вторичный том или в монопольном владении | `ЗАПР. АРХ.` | `tyurin1985-full.txt:18277`-`tyurin1985-full.txt:18289` |

Для каждой заказанной области определяется том; требуемые тома можно определить директивами СКВ и УСТ (`tyurin1985-full.txt:18277`-`tyurin1985-full.txt:18283`).

Особенности экстракода обмена (970 в OCR): авосты `ОШИБКА В ИНФ. СЛОВЕ ЭК.` (номер зоны вне 0..2^N-1, где N - длина области), `ДАЙ ЗАПИСЬ НА МЛ` (не заказана запись на номер), `НЕВЕРНЫЙ ПАРОЛЬ` (не подтверждён пароль) (`tyurin1985-full.txt:18291`-`tyurin1985-full.txt:18305`; ⚠ OCR НЕ ПОДТВЕРЖДЕНО: `970`, «2-1, где Ё - длина области», `ЕВЕРНЫЙ ПАРОЛЬ`, `ВЫ номер`). Экстракоды сдвига для областей работают как для лент / дисков 7,25 Мб, то есть с точностью до зоны, без умножения на коэффициент (`tyurin1985-full.txt:18310`-`tyurin1985-full.txt:18315`).

### 8.6. Бюджетная система архива

Бюджетирование многоуровневое: бюджет архива выделяет ресурсы подразделениям, те - пользователям; каждый бюджет либо для создания нижестоящих бюджетов, либо для создания областей; «оконечные» бюджеты не имеют администратора; бюджет шифра `4..,...` (OCR) имеет неограниченные ресурсы всех видов (`tyurin1985-full.txt:18317`-`tyurin1985-full.txt:18332`). Администратор бюджета может работать от имени подчиненных, уничтожать области из подбюджетов, менять пароли, создавать/изменять/уничтожать нижестоящие бюджеты, перераспределять ресурсы и шкалу групп (`tyurin1985-full.txt:18334`-`tyurin1985-full.txt:18341`).
