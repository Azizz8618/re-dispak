# СПРАВОЧНИК ПО КНИГЕ В. Ф. ТЮРИНА «ОПЕРАЦИОННАЯ СИСТЕМА ДИСПАК» (1985)

Detailed reference guide to the OCR text of the book, assembled by a group of subagents.
Все утверждения имеют ссылки на исходный OCR; сомнительные чтения помечены
`⚠ OCR НЕ ПОДТВЕРЖДЕНО`.

## 1. ИСТОЧНИКИ И МЕТОД

| Ресурс | Назначение |
|---|---|
| `tyurin1985-full.txt` | Сводный OCR, 20 775 строк (`tyurin1985-full.txt:1`, `:20775`) |
| `ocr/page-0001.txt` … `ocr/page-0342.txt` | Постраничный OCR (338 страниц original + служебные) |
| `extract-codes.md`, `extract-codes.json` | Уже распарсенная таблица экстракодов (140 записей, из них 18 low-confidence) |
| `README.md` | Метод OCR, учтённые ошибки распознавания |
| `parse_extract_codes.py` | Парсер приложения П и авторского указателя |

Метод: весь текст разбит на 8 непересекающихся диапазонов строк; каждый диапазон
обработан отдельным субагентом. Цитирование: `tyurin1985-full.txt:<строка>` и
`ocr/page-NNNN.txt:<строка>`. Сверка с материалами проекта (`rukava.be`, `ai/`, `docs/`)
проводилась в каждой части; расхождения зафиксированы, а не скрыты.

Проверка ссылок: из 4 005 ссылок на сводный текст 17 выходят за собственный
диапазон части. Это 6 ссылок на границы смежных глав (1010, 3204, 7506, 10265, 19547)
и 11 кросс-ссылок части 5 на главу 1 (`tyurin1985-full.txt:1565` и др.). Все они
умышленны и указывают на реально существующие строки исходного OCR.

## 3. КАК ПОЛЬЗОВАТЬСЯ

1. Найти тему в таблице раздела 2 и открыть соответствующую часть.
2. Проверить конкретное утверждение по ссылке `tyurin1985-full.txt:<строка>`.
3. Если чтение помечено `⚠ OCR НЕ ПОДТВЕРЖДЕНО`, обратиться к странице OCR
   (`ocr/page-NNNN.txt`) и/или к сверке с проектом в конце части.
4. Для работы с кодами использовать отдельную машиночитаемую таблицу
   [extract-codes.md](extract-codes.md) / `extract-codes.json`.

## 5. ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ

- Исходный PDF — сканированный образ без текстового слоя; OCR выполнялся
  `pdftoppm -r 200 -gray -png` + `tesseract -l rus+eng --psm 3` (`README.md:41-44`).
- Часть чисел и подписей к рисункам не восстанавливается однозначно; они помечены
  `⚠ OCR НЕ ПОДТВЕРЖДЕНО` и перечислены в конце каждой части.
- Книга описывает редакцию ОС 1985 года; текущий проект содержит более поздние
  изменения (1989/2024 и др.). При расхождении авторитетом для текущего кода
  является текст `.be`, а не книга.
