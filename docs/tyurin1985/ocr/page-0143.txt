4.4. Формирование П-задач

Быстродействие ЭВМ таково, что выполнение небольших
П-задач потребует лишь нескольких секунд времени централь-
ного процессора. Поэтому существенно, чтобы запись в списке
выполняемых П-задач можно было бы быстро заменить записью
следующей П-задачи, выбранной планировщиком. Одним из на-
значений планировщика является предварительная подготовка
П-задач, с тем чтобы выполнение не задерживалось и могло
начинаться немедленно. й

Планировщик заранее выбирает П-задачи, которые надо под-
готовить, производит необходимые операции подготовки и затем
передает их из списка имеющихся П-задач в список активных,
который содержит П-задачи, находящиеся на этапе подготовки”
перед выполнением. Обычно П-задачи, относящиеся к фоновым,
не вносятся в список активных П-задач, пока предыдущие П-за-
дачи этих же типов не будут закончены. Так как эти П-задачи
выполняются долго, трудно предсказать, когда будет закончена
предыдущая П-задача, поэтому допускается небольшая задерж-
ка по времени между выполнением этих П-задач.` 5 й

П-задачи, относящиеся к отладочным, вносятся в список
активных П-задач тогда, когда они всего вероятнее будут вы-
браны для выполнения и, если возможно, в этом списке поддер-
живается определенный минимальный запас П-задач для по-
полнения списка выполняемых П-задач подготовленными. Ког-
да новая П-задача требуется для выполнения, рассматриваются
только те П-задачи из списка активных, которые подготовлены
полностью, за исключением случая, когда центральная машина
может быть использована только для того, чтобы начать выпол-
нение частично подготовленной П-задачи.

Подготовка П-задачи включает сбор всей требуемой инфор-
мации, так чтобы после внесения в список выполняемых П-за-
дач задача была доступна центральной машине для решения с
возможно минимальной задержкой. Для полностью подготовлен-
ной П-задачи из списка активных‘ необходимая входная инфор-
мация находится в области ввода, причем все нужные ленты
Установлены и их названия проверены. Поэтому процесс под-
готовки может состоять из считывания входной информации с
буфера ввода, считывания програму, предварительно записан-
ных на буфер ввода, если необходимо введение компилятора в
память и выдачи оператору команды установки магнитных лент
и проверки названия всех таких МЛ (МД). Система Может ис-
пользовать другие периферийные устройства, которые расемат-
риваются как устройства того же класса, что МЛ ‘и’ МД. й под-
готавливаются для работы таким же образом.
