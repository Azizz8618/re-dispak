Все системные задачи можно представить в виде списка,
расположив их в соответствии с установленными для них прио-
ритетами. Для большинства системных задач системные номера
присвоены в соответствии с положением задач в этом списке. Но
поскольку число системных задач превышает числб отведен-
ных для них системных номеров, некоторым низкоприоритетным
задачам системные номера присваиваются из специально вы-
деленного резерва номеров при переводе задач в состояние ro-"
TOBHOCTH.

Таким образом, один и тот же номер может быть присвоен
нескольким задачам, работающим в разное время.

Те системные задачи, Которые не имеют фиксированного
системного номера, отмечаются в шкале ШКПЛАВ. В другой
шкале (ШКШГ) позиционно отмечается резерв выделенных
для них номеров. Тогда при переводе системной задачи в с0с-
тояние готовности системный номер присваивается ей следую-
щим образом:

— если системная задача не отмечена в ШКПЛАВ, ee сис-
темный номер фиксирован и соответствует номеру в приори-
тетном списке задач; -

— если задача отмечена в ШКПЛАВ, ей приписывается но-
мер, который соответствует номеру старшей единицы в ШКШГ;
этот номер фиксируется в строке таблицы ШЗНМБО (номер.
строки соответствует номеру задачи в приоритетном списке).

В соответствии с присвоенным номером в ШГ устанавлива-
ется разряд готовности задачи. Разряд ШКШГ, соответствую-
щий выделенному системному номеру, гасится (системный но-
мер занят).

После окончания работы задачи по ее системному номеру,
находящемуся в ШЗНМБО, будет восстановлена соответствую-
maa единица» в ШКШГ — освободившийся системный номер
может быть использован при переводе в состояние готовности
следующей системной задачи, отмеченной в ШКПЛАВ.
