МЕТОД
-----
1. Растеризация:
     pdftoppm -f 1 -l 85 -r 200 -gray -png <pdf> <tmp>/page
   (временные PNG: /tmp/.private/azizz/opencode/tyurin_a/page-*.png)
   DPI: 200, режим: grayscale, формат: PNG.
2. Распознавание:
     tesseract <png> <outbasename> -l rus+eng --psm 3
   Языки: rus + eng. PSM: 3 (автоматическая сегментация).
   OMP_THREAD_LIMIT=1, параллелизм 4 процесса.
3. Временные PNG удалены после завершения OCR.
