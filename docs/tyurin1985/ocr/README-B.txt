МЕТОД
-----
1. Растеризация:
     pdftoppm -f 86 -l 170 -r 200 -gray -png <pdf> <tmp>/page
   (временные PNG: /tmp/.private/azizz/opencode/tyurin_b/page-*.png)
   DPI: 200, режим: grayscale, формат: PNG. Получено 85 PNG.
2. Распознавание:
     tesseract <png> <outbasename> -l rus+eng --psm 3
   Языки: rus + eng. PSM: 3 (автоматическая сегментация) — основной режим.
   Для явно табличной страницы page-0090 (таблица сигналов ЦП,
   «Рис. 2.7», высокая плотность цифр) применён PSM 6.
3. Временные PNG удалены после завершения OCR.

---------------------
