Работа с бюджетной системой архива. Эксплуатация архив-
ной системы невозможна без контроля за распределением ар-
хивного пространства. Такой контроль осуществляется посред-
ством бюджетирования. Бюджетирование является мпогоуров-
невым: из бюджета архива в целом выделяются ресурсы под-
разделениям; бюджеты подразделений в свою очередь разделя-
ются между пользователями.

Каждый бюджет предназначен либо для создания нижесто-
ящих бюджетов, либо для создания областей. Пользователь мо-
жет создать область, если наинизший соответствующий его
шифру бюджет предназначен для создания областей. «Оконеч-
ные» (предназначенные ‚для создания областей) бюджеты не
имеют администратора, чем и отличаются от бюджетов отделов.
Бюджет архива (т. е. бюджет шифра 4..,...») располагает не-
ограниченными ресурсами всех видов.

Администратор каждого бюджета имеет право фаботать от
имени любого из своих подчиненных. Кроме того, администра-
тор располагает определенными полномочиями по ‘отношению
к созданным из подчиненного ему бюджета областям, в частно-
сти, он может уничтожить эту область, сменить пароль на нее
ит. д. Администратор может создавать, изменять и уничтожать
пижестоящие бюджеты, добавлять или ‚отбирать у них ресур-
сы, изменять им шкалу групп и т. д.
