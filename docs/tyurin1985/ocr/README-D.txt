МЕТОД
-----
1. Растеризация:
     pdftoppm -f 256 -l 338 -r 200 -gray -png <pdf> <tmp>/page
   (временные PNG: /tmp/.private/azizz/opencode/tyurin_d/page-*.png)
   DPI: 200, режим: grayscale, формат: PNG. Получено 83 PNG.
2. Распознавание:
     tesseract <png> <outbasename> -l rus+eng --psm 3
   Языки: rus + eng. PSM: 3 (автоматическая сегментация) — основной режим.
   Для страниц с таблицами предусмотрен PSM 6; в этом диапазоне
   основная масса материала — сплошной текст (описания директив,
   сообщений системы, процедур и таблиц), поэтому оставлен PSM 3.
3. Временные PNG удалены после завершения OCR.
