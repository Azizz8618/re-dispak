Команды задания режимов трассировки.

В стандартном режиме трассировки прослеживаются все
операторы передачи управления. Команда ПВ позволяет отме-
нить трассировку по операторам передачи управления с возвра-
том (CALL, VIM). Команда ЦИК позволяет отменить трассиров-
ку по операторам конца цикла. Команда 970 вводит дополни-.
тельную трасеировку по операторам обмена (экстракодом 070).
Отмена этих режимов происходит при повторном выполнении
соответствующих команд. Отмена и установка режимов трасси-
ровки сопровождается выдачей соответствующей информации на
терминал.

вызова подпрограммы (CALL, VIM).

Команда КНЦ дает пользователю возможность закончить
сеанс отладки. Команда КНЦ с бперандом позволяет активизи-
ровать задачу с указанного места, после чего задача решается,
утратив связь с отладчиком. Перед выполнением этой команды
пользователь должен снять оставшиеся узлы, иначе, если управ-
ление попадет на один из неснятых узлов, задача будет закон-
чена по контролю ‘команды. й

КНЦ ва терминал выдается сообщение: КОНЕЦ СЕАНСА.

с оператором. Команда КНТ без операнда по своим действиям
эквивалентна команде КНЦ без операнда.
