Пользователь обязан сообщить операционной системе, какиё ре-
сурсы. ему необходимы для решения П-задачи и какой системой
программирования он собирается пользоваться, т. е. пользова-
тель должен задать виртуальную машину. В самом деле, с точ-
ки зрения пользователя вычислительная машина с некоторой
системой программирования, например с системой фортран, есть
математическая машина с системой операций, описываемой
фортраном, с вводными и выводными устройствами, описывае-
мыми процедурами ввода-вывода.

Собираясь использовать ОС Диспак, которая с точки зрения
пользователя состоит из нескольких различных виртуальных
машин, он должен выбрать для себя одну из них, на которой
начнет решать задачу, и указать в описании к П-задаче, Если
пользователь хочет дешевле и быстрее решить задачу, он может
по своему усмотрению сократить виртуальную машину, ‘указав
операционной системе состав машины по объему памяти и дру-
гому оборудованию. Пользователь обязан дать название своей
работе (П-задаче).

Идентификация задач и другой информации, относящейся
к ней, также входит в состав языка ОС.

Паспорт П-задачи. Каждая задача, вводимая в вычислитель-
ную систему, должна иметь паспорт, в котором содержится не-
обходимая для решения задачи информация. =:

1. ШИФР — идентификатор пользователя (ШИФР в паспор-
те должен стоять первым);

. 2. ЛИСТ — необходимое количество оперативной памяти для
П задачи; .

3. ВРЕМЯ — примерное время решения П-задачи;

4. ВХОД — адрес первоначального входа в программу П-за-
дачи;

5. ТРАКТ — необходимое количество внешней памяти
на МБ; .

6. ЛЕНТ — виртуальные номера магнитных лент, признак
записи (или считывания) на МЛ (с МЛ), название МЛ;

` 7. ДИСК — виртуальные номера именных дисков, признак
записи (или считывания) на МД (с МД), название МД;

8. АЦПУ — количество бумаги (в метрах) для П-задачи;

9. ЖДЕМ — используется для тех П-задач, которые требуют.
последовательного прохождения в ВС;

10. АВОСТ — присутствие авостного процесса в П-задаче,

- Для нормальной организации операторской службы в ВЦ,
уменьшения числа ошибок при компоновке информации для
П-задач и’ведения сбора статистической информации введена
стандартизация шифров. Для серийных П-задач и трансляторов
можно хранить постоянную часть паспорта в ОС.
