Bee директивы OC Диспак могут быть исполнены с терми-
нала оператора. С терминала пользователя разрешается испол-
нять лишь некоторые директивы оператора.

В ОС Диспак существует возможность задания директив с
тумблерных регистров пульта оператора (пульт управления
ЦП). Информация набирается в 2—8 виде (в работе использует-
ся восьмеричное представление чисел). Правило задания пара-
метров с тумблерных регистров TP6, ТР5, TP4, ТРЗ указывает-
ся в описании директив. Директива выполняется после нажа-
тия кнопки ЗАПРОС на пульте оператора.

Директивы можно задавать с терминала УТ-340, занятого
диалоговой задачей. Для этого достаточно одновременно на-
жать клавиши CTRL и 0, набрать нужную директиву и признак
конца текста ЕТХ. После выполнения директивы на терминал
выдается соответствующее сообщение.

Замечание. Существуют дополнительные возможности
для директив ВКН (cm. 4.2) и ВЦИ (см. 3.2), заданных через
CTRL и 0, приведенные соответственно на с. 38 и 32.

При описании директив используются обозначения:

О — директива оператора. Директива оператора может быть
исполнена только с терминала оператора. :

ОП — директива пользователя. Данная директива может
быть использована как с терминала оператора, так и с терми-
нала пользователя.

СВС — директива используется только для МВК Эльбрус.
