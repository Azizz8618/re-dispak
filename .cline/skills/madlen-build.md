# madlen-build — Сборка МАДЛЕН-программ

## Назначение
Компиляция программ на языке МАДЛЕН (МАшинный ДЛя Экспериментов)
через эмулятор БЭСМ-6 dispak. МАДЛЕН — ассемблер семейства
Электроника-60/64 для тестов и утилит.

## Когда использовать
- Компиляция файлов testdks/*.txt на МАДЛЕН
- Проверка исходников МАДЛЕН перед анализом
- Сборка тестов ДКС (Дисциплина Каналов Связи)

## Ключевые правила комментирования МАДЛЕН

ВАЖНО: правила отличаются от БЕМШ!

| Тип               | БЕМШ              | МАДЛЕН                        |
|------------------|-------------------|------------------------------|
| Строка-комментарий | * текст          | Стекст (С кирилл. в поз. 0!) |
| Инлайн-комментарий | ;текст           | <пробел>.текст               |

### Экспериментально подтверждено:
- С в позиции 0 = строка-комментарий (0 ошибок)
- . после пробела/TAB после операнда = инлайн-комментарий (0 ошибок)
- . как полная строка = НЕ комментарий! (33 ошибки)

### Примеры:
```
С это строка-комментарий           -- работает
С 1Т.Р. 1-15РР — ЗАДАННЫЙ АДРЕС   -- работает
\t    , AAX ,Е24Р .ТЕСТ ВКЛЮЧЕН    -- инлайн работает
. это НЕ комментарий               -- ОШИБКА!
 С это тоже НЕ комментарий         -- ОШИБКА (С не в поз.0)
```

## Формат .b6 файла (обёртка для dispak)

```
шифр 419999 зс5^
лен 41(2048)^
eeв1а3
*name ИМЯ
*no list
*assembler
[исходник МАДЛЕН]
*execute
*end file
``````
еконец
```

- зс5 — активирует МАДЛЕН-транслятор
- *assembler — директива Б6 для МАДЛЕН
- eeв1а3 — бутстрап загрузчика Монитор-80

## Конвертация из .txt формата

Исходники testdks/*.txt используют БЕМШ-формат комментариев (точка).
build_madlen.sh автоматически конвертирует:
- Строки ".текст" -> "Стекст" (С в позиции 0)
- Инлайн ".текст" -> оставляет как есть

## Использование скрипта

```bash
./testdks/build_madlen.sh <source.txt> [ИМЯ_МОДУЛЯ]
```

Действия:
1. Python-скрипт конвертирует комментарии (.->С)
2. Формирует .b6 обёртку
3. Запускает dispak
4. Сохраняет листинг в <файл>.lst
5. Проверяет наличие ошибок трансляции

## Типичные ошибки

| Ошибка              | Причина                         | Решение                          |
|---------------------|---------------------------------|----------------------------------|
| НЕДОПУСТИМЫЙ ОПЕРАТОР | Точка как строка-комментарий   | Заменить на С в позиции 0       |
| НЕДОПУСТИМЫЙ ОПЕРАТОР | С не в позиции 0               | Убрать ведущие пробелы           |
| E50 0133            | Запрос несуществующего устройства | Ожидаемо для тестов ДКС         |
