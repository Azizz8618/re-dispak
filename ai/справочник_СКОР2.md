# СПРАВОЧНИК МОДУЛЯ СКОР2

ИСТОЧНИК: skor2.be (789 строк). СТАРТ '10000'
(лист 4 ОЗУ). УПОТР СКОР2(М5) — база модуля.
Подсистема вызова задач по ключу и шифру.
Связи: ДИСП70, ВЗУ, МОТТ, ПУСКАЧ, ВИСП, КАЧКА,
ДИСКИ, В1К, СОСТАВ.

## 1. НАЗНАЧЕНИЕ
Вызов задач по ключу (короткий идентификатор)
и по шифру. Каталог ключей — зона 675,
таблицы рабочих мест, приоритетные шифры.

## 4. РЕГИСТРЫ ПО ПРОЦЕДУРАМ
- ДС: М13=ПС, М16 (возврат из ВС), М15=-5,
  М10=1 (доп. пробел), М4=конец ключа
- ПДС: М11=-126, М12=М1 (указатель записи)
- ШИФР: М15=6 (символы), М13=ФЗП
- ВШ/ВШ1: М15=-4, М16
- ПРШ (приоритетные шифры): М16=-3+1
- ПРМ (рабочие места): М15=-5+1, М17
- ПОДКЛ: М13, М15=задача из ЯЧКАТ+7, М6=ИПЗ
  задачи, М14=ОСВ
- ПР: М13=ВЫХ2/МОЛ, М17=номер задачи
- КГ: М13=ВЫХ2, М14
