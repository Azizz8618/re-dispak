# СПРАВОЧНИК МОДУЛЯ СМЕНА3 (часть НОМБОБ)

ИСТОЧНИК: smena3.be (593 строки). СТАРТ '11400',
зона загрузки 11400₈ (лист 4 ОЗУ).
Продолжение СМЕНА2: обработка заказов на смену МЛ,
возврат МЛ, поиск замещённых лент, формирование
очередей заказов. Связи: ДИСП70, ВЗУ, ДИСКИ,
ДМЛМБ, КИТ, НОМБОБ.

| М1 | номер бита в шкале / указатель / счётчик |
| М2 | номер задачи / счётчик цикла |
| М3 | база таблиц (КТЗНМЛ, ЗАМЕ, КРМЛ, ЗОН) |
| М4 | номер МГ / номер заказа / счётчик |
| М7 | база модуля СМЕНА3 |
| М10| указатель записи (НОВД+М3) |
| М11| номер заказа / номер направления |
| М12| номер записи / счётчик |
| М13| адрес возврата (стандартный) |
| М14| номер записи / счётчик / номер задачи |
| М15| номер направления / счётчик |
| М16| номер МГ / номер направления / адрес |
| М17| адрес возврата / счётчик |

## 3. РЕГИСТРЫ ПО ПРОЦЕДУРАМ
- ЗАКАЗЫ: М10=НОВД+М3, М3, М7
- ПМ/ВОЧ: М1=номер бита (из НЕД 0), М10, М11=ЗАС
- ЗК/ЗКЫ: М4=МГ/бит, М10 (ВЫБЗ, ЗАКДРБ), М11,
  М17=адрес возврата
- ЗК2/ЗКЗАН: М12=ОБЩ-1, М4, М14, М11, М3
- ЗКЭТ/ЗКАЗ: М2=-15, М4=-1, М15=М7, М12
- ЗК30/ЗК2А: М4, М11 (сброс), М14 (очередь),
  М16 (из ОСКУС1), М2=задача/ШИМЛ
- ЗА: М12 (уменьшение), М10 (восстановление)
- ВП/ВЫП: М4=бит, М11, М15=-6/-15, М3
- ВЫП3/ВЫП5/ВЫП6: М2=задача, М11, М15 (запись
  очереди), М16, М17=ВЫБМГ
- ЗК4А/ЗК4В: М10, М15=ГАШЗАН
