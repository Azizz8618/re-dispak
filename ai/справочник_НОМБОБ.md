Нерезидент ОС: наблюдение за терминалами,
мониторинг МБ/МЛ/МД, печать сообщений, статистика.
Вызывается планировщиком по ШКИВ и из БОЭК1.

## 1. УСЛОВНАЯ КОМПИЛЯЦИЯ

ДА3) и АПБ (.НЕТ).

## 2. КОНТЕКСТ (ИПЗ НОМБОБ, шапка)
Слово 0 СМ; 1: РК=3 (РЖА 3); 2-4: РМР, М33, М32;
5: М27=2003 (режим супервизора); 6-19: М21, М20,
М17..М2; 20: М1=0; 22: СВБОДНО (резерв).
44-е слово ИПЗ портится при печати ТТ (1÷21 рр).

## 3. ГЛАВНЫЙ ЦИКЛ (nombob.be:42-156)
СЧ ФЛАТЕР & Е24П1: если 0 -> НАЧ; иначе сравнение
с ВРЕМЯ (терминальное расписание); при истечении:
УИА 1027, Е47 в ФЛАТЕР, ЕПУСК в ШКИВ (вызов
планировщика), УИА 3.
НАЧ (60): инициализация; МИН из Е48П17/ЕЗАР;
МИНИ/ПМИН/ПМИ2 (64-92): цикл по группам
приоритетов (КМИН, ГРУП, КГРУП, МЧПЗ, НПЗ) —
выбор задачи с минимальным временем из ШКРЗ;
СЧ 33(М17) — 33-е слово ИПЗ (время).
ДЛЯУПР (92): уменьшение БУДУПР (будильник
упрятывания).
ВСЕУПР (96): вход при отсутствии новых заказов;
опрос пав (активность ВУ): ВУЗ/ВОЗ/ВАЗ — цикл
по заказам ВУ (БУР+2-АВМД), печать через ПЧТ
(Е23, ТВ40).
ПБ вдисп/ОБХОДИ (156): ОБХОДИ — СЧ РАБЕ16,
установка Е16 в ШКИВ.
