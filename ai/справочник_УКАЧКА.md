# СПРАВОЧНИК МОДУЛЯ УКАЧКА (зона 010400)

ИСТОЧНИК: ukachka.be (594 строки, документирован,
полные шапки процедур). СТАРТ 4096. УПОТР УКАЧКА(М7).
Управление откачкой задач: периодически проверяет
шкалу УКАЧАЙ, выполняет откачку задач на МБ и РМД.
Запускается по таймеру (будильнику). Не имеет зонгп
в rvs.src — НЕ верифицируется по verify.pl.

## 1. НАЗНАЧЕНИЕ
Откачка задач с рабочих МБ/РМД (УКАЧАЙ) и подкачка
(УКАЧП). Связывает БОЭК1, ДИСП70, ВЗУ, ДИСКИ.

## 2. РЕГИСТРЫ (шапка модуля)
М1, М2, М5-М7, М10, М12, М14-М17.
ВЫЗЫВАЕТ: ЗАХЗАН, ГАШЗАН, ТБУФ, ОТБТБ, ОТБТД,
ФИЗОБМ, ФИЗУР, АНВО9Б.

## 3. ПЕРЕМЕННЫЕ
РЯ7    (19) копия шкалы задач в решении
Е47П39 (21) маска 47-39 разрядов
РЯ     (22) текущая шкала задач в решении
КБЯК   (28) признак повтора обработки
ПОД    (29) 0=откачка, 1=подкачка
РЯ2    (30) адрес обмена
РЯ3    (31) адрес тракта в ТБД
РЯ4    (32) бит канала в СМШГП
РЯ5    (33) признак вида работы
R      флаг "был запрос" (Е48 при старте)

## 4. ИНИЦИАЛИЗАЦИЯ (ukachka.be:34-43)
Сброс R, КБЯК, ПОД=0 (откачка), РЯ5, РЯ, РЯ7;
СЧ Е5 (семафор), УИА УПРИ(М15) (указатель
приписки, ХЛАМ), ПВ ЗАХЗАН(М10) — захват ресурса.

## 5. ПРОЦЕДУРЫ
НАЧАЛО (52) главный цикл: СЧ УКАЧАЙ, если 0 —
        нет заказов (ЕС1); НЕД 0 — старший бит,
        М1 = номер канала; R = Е48 ("был запрос");
        сброс бита в УКАЧАЙ; РЖА 3, УИА 3; НТЖ П60:
        если установлен — ПОИСКТ (аварийное
        закрытие); РЯ5 = бит канала.
ПС1/ПОИСК/ПОИСК1 (68-146) копия ШКРЗ в РЯ7/РЯ;
        поиск задачи в шкале решения: НЕД П77777 —
        номер задачи (М2), ТУСП(М2) — ИПЗ (М3),
        ШЗНМБ(М3), СДА 64+ССТБД — сдвиг к ТБД,
        ПБ ПТА (поиск тракта).
НАЧА (85) пустая шкала: если КБЯК≠0 — повтор,
        иначе сброс БЯК и повтор цикла.
ЕС2 (90-110) освобождение семафора Е5
        (ГАШЗАН); установка Е36 в МШГ; сброс Е47П1
        в ШКИВ; установка всех битов в ШКСВН и
        ШКНПП; выход ПБ БИНОТ2.
ОТБРАК (147-155) ошибка обмена: СЛИА 1(М5),
        счётчик ошибок БЛОБМБ+1 (бит канала).
ТП (156) точка прерывания при ошибке:
        уиа 2, СЧ 2047(М5), уии М4(М5), ПБ ПТА.
ТП4 (111) обработка ШЗНМБ: сдвиг ССТБД, маска
        Е31П17, сброс бита занятости МБ.
ПОИС/ПОИСК1 (123-146) цикл ожидания задач
        в решении (РЯ).
ТП6 (~300-350) откачка: формирование КУС
        (СДА 64-24, СЛЦ РАБМД, РЯ2); ГАШЗАН;
        МОДА НАФИЗ, ПВ (М6); при неуспехе
        ПВ ОТБТД(М16); затем ЗАХЗАН, установка
        бита в ШЗНМБО(М4); ТМБ/ТМД — счётчики
        типов; если ≥7 трактов (ВЧ Е4 -> ВОСТ);
        УКАЧАЙ := Е1; ВОСТ: РЯ5 -> ПВ ВШГП(М15),
        восстановление РЯ4 в СМШГП, ПБ НАЧА.
ЕСП (361-463) обработка запросов подкачки
        (шкала УКАЧП): НЕД 0 — задача (М2),
        сброс бита УКАЧП; проверка ШКРЗ; ТМБ
        (тип МБ); МОД ТУСП-1(М2) — ИПЗ (М3, М4);
        ШЗНМБ(М3), сдвиг ССТБД; ПТД: проверка
        П77777, АКТБД (ИВ ВЧОБ); поиск свободного
        тракта (ГРАНЬБ, ТБД-1(М5)); НД: превышение
        границы -> РЯ2 = адрес обмена (РАБМД,
        Е18 — чтение); ИНФСЛП(М3); ПОБМД — поиск
        куска МД; НАФИЗ; ПТР: ШЗНМБО & Е48П17 —
        занятость кусков; ТРЕ: перенос битов
        занятости ШЗНМБО между трак, обновление
        ТМБ/ТМД.
ПД (464) провал данных: РЗБ НАПРМГ, ЕМБФ,
        МОДА ПОСЛЗП.
НАФИЗ (478-486) начало физ. обмена: ДУК,
        УИА 1027, РМР; РЯ2 | Е19 (флаг записи),
        ПВ ФИЗУР(М16).
ПОСЛЗП (487) ПВ ОТБТБ(М16) при ошибке;
        ПТС: восстановление бита в СМШГП.
ЕС1 (494-507) шкала УКАЧП пуста: проверка R,
        ТМБ; установка Е1 в УКАЧАЙ, ПОД=0,
        ПБ НАЧАЛО (повтор).
ПОМБ/ПОБМБ/ПОБМ/ПОБ/ПОБ1 (508-536) поиск
        обмена с МБ: ПВ ЗАХЗАН; цикл по трак-
        там: ЗОЧ1Б+1(М15), МБКУС-1(М12), ССЫЛКА;
        при неудаче — ПАУЗА.
ПАУЗА/ЗАКРОЙ (537-554) нехватка ресурсов:
        ГАШЗАН (семафор Е5); ЗАКРОЙ: закрытие
        канала (М33), ИВ25/НЗАД; бит в ШСЗПСЧ;
        ПБ АНВО9Б (аннулирование, ВЗУ).
ПОБМД (555-566) поиск обмена с МД:
        ШЗПОМБ & Е40; если 0 — ЗАКРОЙ;
        иначе ПБ ПКУСМД (БОЭК1).
НТ1 (567) СЛИА 1(М5), ПБ НТ (повтор поиска).
