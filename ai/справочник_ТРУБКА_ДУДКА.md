## ЧАСТЬ 1. ТРУБКА (trubka.be)

### 1.1. НАЗНАЧЕНИЕ
Системный модуль управления графопостроителем (ГП):
экстракоды Э52 с кодами 1200-1217 и 1240, выдача
информации на ГП (в т.ч. через нерезидентную бобину
МЛ), обработка прерывания от ГП, диагностика.
Загрузка: 10000₈, 1 лист (modloc.txt: трубка 0315, 1).
УПОТР ТРУБКА(М7) — база модуля в М7.

### 1.2. СХЕМА ВХОДА (trubka.be:35-70)
1. После загрузки: НТЖ 0 — служебный вызов (номер
   задачи 0) → ВЫДТТ; иначе выделить номер задачи (П77).
2. ТУСП-1(М1) → адрес ИПЗ задачи → М2.
3. Сохранить М32 в 3-е слово ИПЗ, обновить М27
   (сброс старших 16 бит через Е48П16 — разрешить
   прерывания), М3 — номер физич. канала/листа.
4. МОДА ЛИСТЧ; вхгп2а (стр.50): ПВ ЗАПВЫХ — запрос
   доступа к странице; слиа -'1200'(М3): код 1200 →
   Э5200, иначе → ЛИСТЧ.
5. Формирование КУС ГП (ЭК 1200): 0-е слово ИПЗ (СМ),
   маска ПРИП+4, биты Е42П1 → КУС7Н; сдвиг 64-10,
   М12 — номер физ. листа; бит 21 (Е21) — признак ГП →
   G10100; иначе '2000' (запрет прерываний), чтение
   40-го слова ИПЗ (УКАЗД), '2003', слово 32 (защита).

## ЧАСТЬ 5. ДУДКА (dudka.be)

### 5.1. НАЗНАЧЕНИЕ
Драйвер ГП «БЕНСОН» для конфигурации НИТИ
им. Александрова. Загружается из ТРУБКИ при вызове
экстракода Э52 1210 (или 1216/1217) через гпнити.
Загрузка: 10000₈, 1 лист (modloc.txt: ДУДКА 0002, 1).
УПОТР ДУДКА(М16) — база модуля; М7 — БЕНСОН.

### 5.2. АЛГОРИТМ (шапка dudka.be:1-42)
1. Выделение двух буферных листов ОЗУ через ТБУФ.
2. Формирование двух КУС: D10164 (чтение из внешней
   памяти в буфер) и D10163 (запись кадра в БЕНСОН);
   оба содержат бит 27 (признак ГП) и номер
   устройства/направления (маска D10120).
3. Инициализация БЕНСОНА: в спец. регистр РЕГ '34'
   последовательно записываются 9 управляющих слов
   (маски Е28, Е28Е25, Е28Е21, D10171).
4. Подмена вектора прерывания обвнп1+30 (18-й разряд
   ГРП); новый обработчик — ВХОД.
5. Основной цикл: вызов вдудку формирует кадр;
   ФИЗОБМ передаёт его в БЕНСОН; по прерыванию из
   РЕГ '240' читается слово данных; после заполнения
   буфера — переключение буферов и пробуждение задачи.
6. По завершении всех кадров (бит 48 во 2-м слове
   ИПЗ) БЕНСОН сбрасывается (РЕГ '34'), вектор
   прерывания восстанавливается, буферы возвращаются
   через ТБУФ (бит 19).

Регистры и команды: РЕГ '34' — запись команды
управления; РЕГ '240' — чтение слова данных;
УВВ '4023' — опрос состояния (в ТРУБКЕ); УВВ 7 —
команда физического обмена; ТВ67/ТВ67А —
установка/гашение масок ГРП.

### 5.3. ТОЧКА ВХОДА (dudka.be:44-59)
СТАРТ '10000'; мод БНСО: М16 := базовый адрес ДУДКИ.
Далее чтение параметров вызова из ИПЗ (4-е слово,
М32): М5 := М32-1, чтение по М5, сохранение в D10154.
Формирование КУС: сбр П77, рзб D10120, или е27гп,
зп D10164 (чтение); повторно со сдвигом 64+6 →
D10163 (запись). Выделение листов через ТБУФ:
G10015 (стр.93) — первый буфер (адрес в D10161,
текущий D10160; КУС+сдвиг 64-2, бит Е18, ФИЗОБМ);
G10024 (стр.109) — второй буфер (D10162, КУС D10163).

## СВЯЗЬ ТРУБКА ↔ ДУДКА
- ТРУБКА гпнити (стр.679) обрабатывает коды Э52
  1210-1217 (слиа -8) и загружает ДУДКУ.
- ДУДКА использует базу ДИСП70 БНСО и вектор
  обвнп1+30; обратные точки — БЕНСОН (ошибка, вдудку).
- В ТРУБКЕ для К-71 есть входы вхгп2а..вхгп2е
  (МОТТ, шзанл7) — взаимодействие с ДКС.
