## НАЗНАЧЕНИЕ
Часть нерезидентного модуля НОМБОБ (части: смена,
смена1, смена2, смена3; зона сме 0277, смена1-3
0300-0302 modloc.txt). Реализует логику перемещения
и обмена дисков между устройствами, включая общие
диски между машинами комплекса (К-71). Тесно связан
с АВМД (аварийная обработка МД) — многие рабочие
ячейки (Р, Р2, Р3, Р5, НОВ1, НВ2, НМД, ПЕРЕСТ, ДР,
ВКЛ, У, А, ЭТОТ) берутся из области АВМД
(смещение -А(М7)).

## ЗАГРУЗКА
СТАРТ '10000' (sme.be:8).
modloc.txt: сме 0277, 1 лист.
База модуля: М7 = СМЕ (ЭКВИВ С1=СМЕ, sme.be:642).
УПОТР СМЕ(М6) — рабочий регистр модуля М6 (sme.be:9).

## ВХОД
ВХОД ВСМЕ, ЕСТ, МДЕСТ (sme.be:641).

## ТОЧКА ВХОДА (sme.be:20-28)
Проверка совпадения номера зоны и определение
действий при смене диска.
ВХОД: М1 — номер устройства (источник),
      М2 — номер устройства (приёмник),
      М3 — номер направления источника,
      М4 — номер устройства внутри линии,
      М7 — база модуля СМЕ (СМЕ-А).
Логика: слово по 454(М3) сравнивается с ТЗНМД+У(М4)
приёмника; по маске П7777 (12 бит номера пакета).
Совпало → ВКЛ; не совпало → ЕСТ (смена).

## СВЯЗЬ С ДРУГИМИ МОДУЛЯМИ
- Часть пакета НОМБОБ (нерезидент). Активируется
  при смене диска (сравнение ТЗНМД).
- Взаимодействует с АВМД (общие ячейки -А(М7)):
  ЭТОТ, НОВ1, НВ2.
- Результаты: обновление НФИЗ, ТЗНМД, очередей
  ШОЧМД/ШОЧЛ/ШОЧНМД, ОЖОСВ, ИЗАХВ, ОБЩТОМ задач,
  НМД (шкала новых дисков).
- Прерывания: блокировка УИА 1027 на время
  операций со шкалами, разрешение УИА 3.
