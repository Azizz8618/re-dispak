# ФАКТЫ КОНФИГУРАЦИИ И ЗОН ОС ДИСПАК

Документ собран как опорный фактологический слой для разрешения пометок ⚠ в `ai/карты/карта_*.md`.
Источники только читались. Файлы `.be`, `.lst`, `.tab`, `rvs.src`, `modloc.txt` и существующие карты не изменялись.

## 0. МЕТОД ПАРСИНГА И СЕМАНТИКА ЧИСЕЛ

1. `rvs.src` читался по строкам. Шаблон строки:
   `мдл <имя> 43zzzz^наз <адрес>^зонгп <43ZZZZ> <N>^`.
   Парсер извлекал: имя модуля (включая слитное написание вида `печать43zzzz`),
   поле `43zzzz` (или `42NNNN` в закомментированных строках 139-157),
   поле `наз`, поле `зонгп` (4 цифры зоны и число секторов N).
   Строки, начинающиеся с `#`, помечены как исторические и в таблице имеют префикс `#`.
   Итого: 138 активных строк (1-138) и 19 закомментированных (139-157).
2. `modloc.txt` читался как `<имя> <последовательный адрес> <длина в листах>`.
   Всего 143 модуля (строки 2-143).
3. Семантика трёх разных чисел, что подтверждено кодом `rvs.pl:41-43` и `verify.pl:12,49-55`:
   - `43zzzz` это номер зоны на диске 43 сборки. Скрипт `rvs.pl` заменяет `zzzz`
     на последовательный адрес из `modloc.txt`. Например `печать` из `rvs.src:1`
     превращается в `430204`, потому что `modloc.txt:71` даёт `0204`.
   - `наз` это адрес загрузки модуля в ОЗУ БЭСМ-6 (восьмеричный).
     префикс `нс` (`наз нс010400`, 38 случаев) в картах трактуется как адрес
     нерезидентной загрузки; прямого определения `нс` в RUKAVA нет, это
     рабочая интерпретация карт, не первичный факт.
   - `зонгп 43ZZZZ N` это зона системного диска, куда модуль записан для
     проверки, и число 1536-словных секторов (N=4 означает всю зону 6144 слова).
     `verify.pl:54`: зоны с номером < 512(10) читаются с диска 2053,
     зоны >= 1000(8) с диска 2048.
   Эти три числа НЕ взаимозаменяемы. Путаница между ними главный источник ⚠ в картах.
4. Для сопоставления с картами имя модуля `rvs.src` транслитерировалось в имя файла
   карты с учётом принятых в проекте написаний (`связь7` -> `SVYAZ7`,
   `э71тк` -> `E71TK`, `пибэсм` -> `PIBESM`, `часы` -> `CLOCK`).
   Из паспорта карты (первые 22 строки) брались поля `СТАРТ`, `Зона`,
   `Зона/стартовый адрес`, `Зона загрузки`.

Все числа ниже восьмеричные, если явно не указано иное.
