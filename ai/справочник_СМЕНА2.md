# СПРАВОЧНИК МОДУЛЯ СМЕНА2 (часть НОМБОБ)

ИСТОЧНИК: smena2.be (297 строк). СТАРТ '11400',
зона загрузки 11400₈ (лист 4 ОЗУ).
УПОТР СМЕНА2-768(М7) — М7 база модуля.
Часть нерезидента НОМБОБ: обработка смены МЛ,
возврат МЛ, заказ МЛ, перенос заказов при смене.
Вызывается из НОМБОБ (точки ДРБ1, ДРБЭ2).

## 1. НАЗНАЧЕНИЕ
Обеспечивает обработку смены МЛ, возврат МЛ,
заказ МЛ, перенос заказов при смене.
Вызывает процедуры из ДИСП70, НОМБОБ.

## 2. РАБОЧИЕ РЕГИСТРЫ (постоянное назначение)
| Рг | Назначение                                     |
|----|------------------------------------------------|
| М1 | адрес заказа / номер бобины / указатель записи |
| М2 | счётчик цикла / признак типа обработки         |
| М3 | база таблиц (КТЗНМЛ, ЗАМЕ, ЗАКДРБ)             |
| М4 | номер МГ / номер заказа / указатель            |
| М7 | база модуля СМЕНА2                             |
| М10| указатель второй группы заказов (НОВД+2)       |
| М11| указатель КТЗНМЛ / номер заказа                |
| М12| указатель записи в таблицах / номер МГ         |
| М13| адрес возврата (стандартный)                   |
| М15| признак / адрес возврата                       |
| М16| номер бита в шкале / номер заказа              |
| М17| указатель первой группы заказов (НОВД)         |

## 4. АЛГОРИТМ ДРБ1 (строки 96-100)
СЧ ПРБ-Н(М7): 0 → ЗАК5; иначе УИА '3'
(разрешение прерываний), СЧ ЯЧВОЗ-Н(М7):
0 → ВЗВ (возврат МЛ).

## 5. РЕГИСТРЫ ПО ПРОЦЕДУРАМ
- ДРБ1: М2=-1, М17=НОВД+М3, М10=НОВД+2+М3,
  М15=1, М1=М17, М11=КТЗНМЛ
- ЗАК/ЗАК2: М16=номер бита, М12=М16+М3 (ОЧКУС1),
  М15=КТЗНМЛ
- ЗАК3: М16=номер бита
- ЗАК4: М1=М10 (вторая группа), М15=0
- ЗАК5: М13=адрес возврата, М4=номер МГ (ШОЧМГ)
- ВЗВ: М4=номер МГ, М1=НОВД+2-1+М3, М10=1
- ЗАК1: М4, М11=КТЗНМЛ, М13
- ПМЛ2/ПМЛ3/ПМЛ6: М15=М4-32, М11, М4=номер МГ
- ДРБЭ/ДРБЭ2: М16=АРВЭ1, М1=номер бобины,
  М4=МГ+бобина, М3=база таблиц
