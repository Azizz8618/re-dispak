# СПРАВОЧНИК МОДУЛЯ СВЯЗЬ7 (зона 0677)

ИСТОЧНИК: svyaz7.be (1755 строк). СТАРТ '40000'.
Организация связи БЭСМ-6 — ДКС через КАДОПАМ.

## 1. ВХОДНАЯ ИНФОРМАЦИЯ (svyaz7.be:8-18)
М2     номер терминала
М3     слово ДКС
М4     рабочий регистр "СВЯЗЬ7" (база модуля, УПОТР)
М5     N направления КРК
М7     база вызывающего (Э71ТК или БОНБОТ)
41(М7) адрес конца выдаваемого массива + 1
42(М7) для первого входа — слово Н-машины
М10    адрес информационного поля терминала
М13    адрес начала буфера S-терминала
М14    рабочий при работе с АС ДКС
М16    адрес буфера S-терминала
М17    рабочий

## 2. ЛОГИКА АКТИВАЦИИ (шапка модуля)
При вызове Э50 '133' НЕ загружается; загружается при
установке направления КРК=0. Начало: УИА '2003'
(блокировка прерываний), проверка ШКОРАБ & ЕЗВ
(будильник) -> зптерм; иначе шкала шзпри7 & ШКЭ71,
выделение терминалов ДКС (шкут), установка будильников
(устбуд) и пометка в ШКОРАБ.

## 3. ПРОЦЕДУРЫ (по AGENTS.md §12.6 и тексту)
НТЕРМ7  подключение терминала, инициализация
        буфера S-машины
ПРП5    внимание/быстрый обмен: чтение
        kadopam_mem[0154]
ПРП6    готовность приёма: запись в буфер H-машины
ПРП7    запрос ввода H-терминала: символ в МОТТ
ПРП8    готовность передачи: ответ на терминал
ПРП12   запрос S-терминала: системный буфер
тстдкс  (svyaz7.be:92) вход через НБОБ: установка бита
        в рсвсм1, слово СМ в рсвясм(М16), переход общий
диспчр  (svyaz7.be:81) диспетчер по номеру запроса:
        трмдкс / обмедл / выднаh
зптерм  (svyaz7.be:64) обработка запросов шкраб7,
        нед Е15П1, снятие бита, диспчр
устбуд  (svyaz7.be:53) активация будильника: E41 в
        ВППС(М16), ЕЗВ в ШКОРАБ, бит в ШБУДИЛ

## 4. К-71 ВХОДЫ

## 5. СВЯЗЬ С ЭМУЛЯТОРОМ
ПРП5-8,12 -> kadopam_svc() в besm6_cpu.c;
kadopam_mem — uint16_t[65536]; доступ через
команды 032 (кк 26,'0' — чтение) / 033 — запись.
Карта: 0154 команда подключения, 0155 номер
терминала, 0156 адрес буфера S; 002000+ буферы
S-терминалов; шаг 0x100 (256 слов) на терминал.

## 6. АВТОЗАГРУЗКА (см. справочник_ДИСП70 §11)
ПРП6 -> ОБВНП3 -> свядкс -> загруз (konfus.be:870):
E24 в ШГ, аивсв7 в ТУС-1+'31' -> БПУ подкачивает
ИПЗ СВЯЗЬ7. Э50133 выполняется внутри загруженного
СВЯЗЬ7 (кк 26 — чтение РКС).

## 7. АППАРАТНЫЙ УРОВЕНЬ ОБМЕНА (test_k71.txt)

Связь БЭСМ-6 ↔ ДКС на аппаратном уровне
описана в testdks/test_k71.txt (НИТИ, 2005/2024).

### Регистры ДКС (сторона Э-60)
| Регистр | Адрес    | Назначение                           |
|---------|----------|--------------------------------------|
| РСС     | 177100   | Слово состояния КАДОПАМ             |
| РБП     | 177000   | Регистр буфера прерываний (9 слов)  |
| РПР     | 032-чт.  | Регистр приёма прерываний (сравн.)  |

### Два режима обмена
- Режим 1: запись 1 слова без прерывания
- Режим 2: запись 9 слов в РБП + прерывание

### Программа-загрузчик
В test_k71.txt (ячейки 02036–02067) содержится
программа-загрузчик, записываемая в ОЗУ ДКС.
Она устанавливает начальные значения регистров
и запускает тест профконтроля.

## 8. ТЕСТИРОВАНИЕ ОЗУ ДКС С БЭСМ-6 (test_sis_k71.txt)

Тест выполняется на БЭСМ-6 в автокоде МАДЛЕН
и обращается к ОЗУ ДКС через КАДОПАМ.
Команды 132/032 (МАДЛЕН Z13/Z03) — не входят
в стандартный набор команд БЭСМ-6, придуманы
специально для обмена через КАДОПАМ (К-71).

### Диапазон проверяемой памяти
10–67777₈ (ячейки ОЗУ ДКС, доступные
через КАДОПАМ с БЭСМ-6).

### Подтесты (7 шт.)
| №  | Название        | Описание                     |
|----|-----------------|------------------------------|
| 1  | Зап.-чт.по адp.| Запись и чтение по одному    |
| 2  | Перебор адресов | Последовательный обход       |
| 3  | Единицы         | Запись всех 1, проверка      |
| 4  | Нули            | Запись всех 0, проверка      |
| 5  | Бегущая 1       | Сдвиг 16-разрядной единицы   |
| 6  | Бегущий 0       | Сдвиг 16-разрядного нуля     |
| 7  | Произвольный    | Константа 113351₈            |

### Команды БЭСМ-6 в автокоде МАДЛЕН
| Команда МАДЛЕН | Код     | Назначение                    |
|----------------|--------|---------------------------------|
| Z13,адрес      | 132*   | Запись в ОЗУ ДКС через КАДОПАМ|
| Z03,адрес      | 032*   | Чтение из ОЗУ ДКС через КАДОПАМ|

\* Команды 132/032 НЕ входят в стандартный
  набор команд БЭСМ-6. Расширение для КАДОПАМ (К-71).
В обеих командах читается нулевой адрес
КАДОПАМ (обращение к адресу 0).

### Значение для проекта
Тест доказывает, что ОЗУ ДКС доступно для
полноценного тестирования с БЭСМ-6 через
нестандартные команды КАДОПАМ (132/032,
МАДЛЕН Z13/Z03). Диапазон 10–67777 уточняет
заявленный в rukdks.be "00000–77777".
