## 5. СВЯЗЬ С ЭМУЛЯТОРОМ
ПРП5-8,12 обрабатываются в dks_svc() (besm6_dks.c).
Память КАДОПАМ — 4 канала × 32768 16-битных слов
(uint16_t e60_mem[4][32768]), канал = индекс массива.
Доступ через команды 032 (чтение) / 132 (запись).
Ячейка 0 канала 0 возвращает DKS_STATUS(02000) |
слркс0 | счётчик.

**Соответствие ПРП ↔ канал КРК:**
разряд ПРП = 8 − код канала.
ПРП8 → канал 0, ПРП7 → канал 1,
ПРП6 → канал 2, ПРП5 → канал 3,
ПРП12 → счётчик «внимание».

Адреса буферов в каналах (svyaz7.be:1509-1529):
абуфs[0]=0110, абуфh[0]=0132, абфосs[0]=0154,
абфосh[0]=0157, адркс0=77775 (ведущая Э-60).

## 6.1. ПОЛНАЯ ЦЕПОЧКА ЗАГРУЗКИ (2026-09-17)

СВЯЗЬ7 НЕ загружается автоматически при старте ОС.
Цепочка загрузки:

1. **НОМБОБ** (нерезидент) вызывается планировщиком
   по ШКИВ (бит Е16).
2. При достижении `диасм7` (nombob.be:322) и
   конфигурации К-71 → `пб нстдкс` (konfus.be:930).
3. **нstdкс** (конфус.be:930-951):
   - `сч базсв7` — проверка: загружен ли СВЯЗЬ7?
   - Если нет → `пв ТБУФ(М15)` — запрос страницы ОЗУ
   - Формирование КУС = `КУССВ7 | базсв7 | НОММЛ1`
   - `пв ФИЗОБМ(М16)` — чтение модуля с МЛ
   - Цикл `нсдкс1` — копирование 4 векторов из
     таблиц `уходы`/`адреса` СВЯЗЬ7 в **ОБВНП3**
4. **свядкс** (конфус.be:961-1007) — основной цикл:
   - Чтение РКС (`кк 26,'0'`)
   - Установка МПРП (биты 6,12)
5. **загруз** (конфус.be:887-917) — настройка планировщика:
   - E24 в ШГ → БПУ подкачивает ИПЗ СВЯЗЬ7

### Загрузка не зависит от ПРП6 (уточнено 2026-09-17)
До загрузки СВЯЗЬ7 векторы ПРП5-8 в ОБВНП3
содержат заглушки (`пб БМВ`, disp70.be:1607-1613).
Это **не** циклическая зависимость:
- ПРП6 → заглушка `пб БМВ` → простой возврат
- СВЯЗЬ7 загружается **независимо** от ПРП6,
  через НОМБОБ → КОНФУС.нстдкс → ФИЗОБМ

**Разрешение:** НОМБОБ запускается планировщиком
по ШКИВ (Е16). `нстдкс` загружает СВЯЗЬ7 с МЛ
и подменяет векторы в ОБВНП3.

### Для эмулятора
Если ОС загружена, но СВЯЗЬ7 не активна:
- **Вариант А:** Установить бит Е16 в ШКИВ для
  запуска НОМБОБ → КОНФУС → загрузка
- **Вариант B:** Реализовать прямую загрузку
  СВЯЗЬ7 из образа МЛ (минуя нстдкс)

## 7. ДЕШИФРАТОР Э50 '133' (Э50133, svyaz7.be:959–1006)

### 7.1. Входные параметры
При вызове Э50 '133' аппаратура генерирует ловушку; ДИСП70 передаёт
управление в ЭКВВОД → ВЫЗ7 → ЭК7 (Э133) → СВЯЗЬ7 (Э50133).

| Регистр | Значение | Источник |
|---------|----------|----------|
| М3      | Указатель на ИПЗ задачи (слово состояния) | ЭКВВОД ТУСП-1(М2) |
| М2      | Номер команды (133₈) | ЭКВВОД ПОЧТА |
| (М3)    | ИС = слово состояния задачи (ИПЗ[36]) | Аппаратура БЭСМ-6 при ловушке Э50 |

### 7.2. Битовая карта ИС (информационное слово)

ИС = значение СМ в момент выполнения команды Э50.
Аппаратура сохраняет его в **ИПЗ[36]** (слово состояния задачи).

```
Бит: 48         36 34                 12  7  3  1
     ├──ДЛЯ ОПИСАНИЯ──┤  ├── КОД НЗАД ──┤  ├──┤
     │ 12 бит (37-48)  │  6 бит (7-12) │3(1-3)│
     │   код группы    │  НЗАД 20-37₈  │ КРК  │
     └──────────────────┘────────────────┴─────┘
         ↓ Е48П43           ↓ СДА+ИП77    ↓ И П7
      СЧЕТПР+5          М12 (задание)  М5 (КРК 0-7)
```

**Расшифровка полей:**

| Биты ИС | Назначение | Извлечение | Назначение |
|---------|-----------|------------|------------|
| 1–3     | Номер направления КРК | `И П7` → М5 | К-71, выбор канала (0–7) |
| 7–12    | Код операции (задания) | `СДА 64+6; И П77` → М12 | 0 → нетест; 20₈–37₈ → НЗАД |
| 36      | Признак режима (для КРК=3) | `И Е36; СДА 64+35` | Обновление кодтип для КРК=3 |
| 37–48   | Код группы (12 бит) | `НТЖ Е48П43; СДА 64-12; СЧМР` → СЧЕТПР+5 | 0 → ошибка; 60₈ → гшпрп; 3260₈ → трассировка |

### 7.3. М13 в Э50133

```
Строка 962:  УИИ М13(М3)    ; М13 := М3 (= ИПЗ задачи)
```

- **Обычный режим:** М13 = М3 = ИПЗ (указатель на слово состояния = ИС)
- **«Нетест» (ИС=0):** М13 = 0 (ekvvod_edited.be:78 — `ВВОДМ: УИА 0(М13)`)
- М13 сохраняется на протяжении процедуры; М3 может быть изменён (строка 978).

### 7.4. Роль М3: разное написание одного слова

ИПЗ[36] = слово состояния задачи = ИС.
- В ЭКВВОД (строка 68): `36(М3)` — ТУСП[command] = ИПЗ, смещение 36 → чтение слова состояния
- В СВЯЗЬ7 (строка 963): `(М3)` — М3 уже указывает на слово состояния (или `(М3)` = обращение к тому же слову через иной сдвиг)

Фактически `(М3)` в СВЯЗЬ7 и `36(М3)` в ЭКВВОД — одно и то же слово:
**слово состояния задачи** (ИПЗ[36]).

### 7.5. Особенности КРК₀ (биты 1–3 ИС = 0)

| Черта | Описание | Строка |
|-------|----------|--------|
| Загрузка модуля | СВЯЗЬ7 загружается ТОЛЬКО при КРК₀ | svyaz7:28 |
| Задержка КАДОПАМ | Программный цикл при записи в буфер 70000 | svyaz7:227 |
| Ручной режим | ЗПРОС1: проверка `ручной` (E48(М5)); если нет → `непоня` | svyaz7:292 |

### 7.6. Мёртвый код в ЭКВВОД (ekvvod_edited.be:55–56)

```
55:  СЧ  обвнп1+24+4    ; СМ := обвнп1+28 (адрес таблицы)
56:  СЧ  0              ; СМ := 0  ← НЕМЕДЛЕННО ПЕРЕЗАПИСЫВАЕТСЯ
57:  ЗП  РАБАД          ; РАБАД := 0  (результат строки 56)
```

Строка 55 вычисляет адрес таблицы обработки, но никуда не сохраняет
результат — строка 56 немедленно обнуляет СМ. Результат строки 55
не используется. Вероятно остаток от раннего варианта кода, где
обвнп1+28 был нужен для косвенного перехода.

## 8. ИНФОРМАЦИОННОЕ СЛОВО (ИС): ПОЛНЫЙ МЕХАНИЗМ СОХРАНЕНИЯ

### 8.1. Момент сохранения

1. Программа загружает ИС в СМ
2. Выполняет КОНД В'133' (код операции 050)
3. Аппаратура генерирует ловушку Э50
4. СМ сохраняется в **ИПЗ[36]** = слово состояния задачи

### 8.2. ТУСП и М3

```
ТУСП[command] = ИПЗ_задачи + 36    (адрес слова состояния)
```

ЭКВВОД загружает М3 из ТУСП по номеру команды:
```
ЭКВВОД:66:  СЧ ТУСП-1(М2)     ; М2 = номер команды
ЭКВВОД:67:  УИ М3              ; М3 = ТУСП[command] = ИПЗ + 36
```

В СВЯЗЬ7 (Э50133) `(М3)` даёт ИС, т.к. М3 уже указывает на ИПЗ[36].

### 8.3. Диспетчеризация ИС

| Условие | Ветка | Действие |
|---------|-------|----------|
| ИС[7–12] = 0      | нетест   | М12 = 0; стандартный режим |
| ИС[7–12] = 20₈–37₈| «тест»   | М12 = НЗАД; задание |
| ИС[7–12] < 20₈    | эошиб3   | Ошибка E3 |
| ИС[7–12] > 37₈    | эошиб3   | Ошибка E3 |
| ИС[37–48] = 0     | э133ош   | Ошибка: код группы 0 |
| ИС[37–48] = 60₈   | гшпрп    | Гашение ПРП |
| ИС[37–48] = 3260₈ | изсв7    | Трассировка КОНЕЦ1 |

## 9. ОБЩАЯ СХЕМА ОБРАБОТКИ ИС ЛЮБОГО ЭКСТРАКОДА

(выведено при анализе Э50 '133', применимо ко всем экстракодам ЭКВВОД)

### Стадия 1. Аппаратная ловушка

Аппаратура БЭСМ-6 при выполнении команды ЭXX генерирует ловушку.
Содержимое СМ (аккумулятора) = текущий информационный сегмент (ИС)
сохраняется в **ИПЗ[36]** («слово состояния задачи»).

### Стадия 2. ДИСП70 → ЭКВВОД

Диспетчер ОС ДИСП70 обрабатывает причину ловушки и передаёт управление
в **ЭКВВОД** (эквивалент ввода — общий обработчик экстракодов).

### Стадия 3. ЭКВВОД — чтение и первичное декодирование ИС

```
ТУСП[command] = ИПЗ_задачи + 36
М3 := ТУСП[command_number]           ; указатель на слово состояния
ИС  := (М3)                          ; СМ = ИПЗ[36]
М2  := ИС & П77                      ; младшие 6 бит ИС → номер команды
ЗП  ПОЧТА                            ; сохр. для диспетчера серии команд
```

### Стадия 4. ВЫЗx / ВЫЗA — подкачка модуля-обработчика

```
ВЫЗ7:   М16 := КЭК7-Э               ; адрес таблицы прикрытия ЭК7
ВЫЗA:   проверка кеша (НСЕ)
         ДА  → прямой переход на обработчик
        НЕТ → ФИЗОБМ (загрузка модуля с диска) → переход
```

Иногда модуль уже в памяти (СВЯЗЬ7 загружается при КРК₀);
иногда — требуется физическая подкачка (см. svyaz7.be:18–27).

### Стадия 5. Конкретный обработчик — декодирование полей ИС

Каждый экстракод имеет собственный дешифратор ИС. Для Э50 '133' —
см. §7.2 выше. Общие поля:

| Поле ИС    | Назначение                         | Пример использования |
|------------|------------------------------------|----------------------|
| Биты 1–3   | Адресный подрегистр (ср. b0–b5)   | Номер КРК (Э50 133) |
| Биты 7–12  | Код операции                       | НЗАД / подкоманда |
| Биты 13–36 | Основное поле данных              | Адрес буфера, параметры |
| Биты 37–48 | Код группы / старшие биты         | Группа абонентов (Э50 133) |
| Бит фото   | Спец. признак (чр. ДИСП70:71 → Е31) | (см. ДИСП70, §8 below) |

### Бит фото (чр. ДИСП70:71): lệnh 70, КВ 77

При чтении 71-го слова ИПЗ в ДИСП70 (dsp70.be:511–516) происходит
проверка бита фото (чр. «фото»):

```
dsp70.be:511:  СЧ  71(М15)         ; СМ := ИПЗ[71]
dsp70.be:512:  И   Е48П48          ; выделить 48-й бит (чр. фото)
dsp70.be:513:  ПО  ВЫХ1            ; если 0 → пропустить гашение
dsp70.be:514:  СЧ  71(М15)         ; СМ := ИПЗ[71]
dsp70.be:515:  К77 '700'           ; команда гашения фотоэлемента
```

Команда 70 (чр. фото) используется трассировочной аппаратурой;
К77 с полем '700' — специальная аппаратная операция (чр. ДИСП70 на БЭСМ-6).
