## 1. НАЗНАЧЕНИЕ, ЗАГРУЗКА, ТОЧКИ ВХОДА

Управление обменом с магнитными лентами ЕС-5017,
подключёнными к БЭСМ-6 через аппаратуру сопряжения:
подвод, запись, чтение, разметка, обработка ошибок
и прерываний (шапка esml.be:1-17).
Взаимодействует с ДМЛМБ, ВЗУ, ДИСП70, КИТ, НОМБОБ,
ПРИКАЗ, ХЛАМ.

Загрузка: СТАРТ '62000' (шапка: лист 31 ОЗУ);
modloc.txt: есмл 0121, 3 листа. Секции: Е (данные),
М (команды).

Точка входа START (esml.be:32) — по прерыванию от
ЕС-5017 при появлении признака в МЛЕС:
1. МЛЕС=0 → врмл; иначе +1 (счётчик входов).
2. Разряд 17 (нтж Е17) сверка с ШР+1 → G62062.
3. Таймер ДОП ≠ 0 → врмл; ШЗЗОБМ (ожидающие
   обмена) ≠ 0 → врмл.
4. МГЗ & Е32П25 (занятые МГ) = 0 → G62026.

Дополнительные входные точки: закес (1309),
устмгз (1843) — полный список в разделе 6.
