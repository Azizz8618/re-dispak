# СПРАВОЧНИК МОДУЛЯ ТЕРМ (зона 0440)

ИСТОЧНИК: term.be (747 строк, полная версия).
СТАРТ '7255' (term.be:49). Подготовка массива для
выдачи на терминал (телетайп, видеотон, консул).
Общий блок для БОНБОТ и Э71ТК (повторная входимость
при нехватке выделенного буфера).

## 1. НАЗНАЧЕНИЕ (term.be:1-48, шапка)
Настройка по типу терминала, перекодировка символов
(таблица ТАБКОД), запись в буфер (рекорд),
управление регистрами (рус/лат/цифры), обработка
управляющих кодов (NL, КС, ЕТХ, STRLO...).
В качестве рабочих используются ячейки 41 модулей (М7).

## 6. ТАБЛИЦА ПЕРЕКОДИРОВКИ ТАБКОД (term.be:562-688)
128 слов (индексы 0-177₈). Каждое слово — 6 байтов
по 8 бит. Сдвиг (М6) выбирает байт:
| Сдвиг | Разряды | Назначение                        |
|-------|---------|-----------------------------------|
| 0     | 48-41   | ТТ РУС (МТК-2)                    |
| 8     | 40-33   | ТТ ЛАТ (МТК-2)                    |
| 16    | 32-25   | ТТ ЦИФРЫ (МТК-2)                  |
| 24    | 24-17   | ВТ-340 РУС (КОИ-7, инвертир.)     |
| 32    | 16-9    | ВТ-340 ЛАТ (КОИ-7, инвертир.)     |
| 40    | 8-1     | КОНСУЛ (CONSUL, 8-бит)            |
Коды ВТ-340 инвертируются и разворачиваются
процедурой vton4 перед выдачей.
Примеры (term.be:562-572): 000 = '4003016200100017'
(УПП 000 пусто), 001 = 'Т', 002 = 'Щ', 003 = '5',
010 = '>', 011 = 'L', 012 = 'S'.
Примеры конца (685-689): 173='[', 174='\\', 175=']',
176='↑', 177='←'.
ККОДПЛ (term.be:88-107) — отдельная таблица 16
констант (КОНД): регистры ЕЭ3;РУС;ЛАТ,РУС,ЦИФ и т.д.

## 8. ШКАЛЫ ДКС

               vzu.be:2255).

               с ДКС; устанавливается при начале
