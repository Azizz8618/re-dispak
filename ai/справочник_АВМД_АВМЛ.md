## ЧАСТЬ 3. АВМЛ (avml.be)

### 3.1. НАЗНАЧЕНИЕ
Аварийное завершение обмена с МЛ и формирование
распечатки ошибок МЛ. Вызывается из ДМЛМБ при
обнаружении ошибки обмена (вход через метку АВ или
процедуру ПРОШ1 из ЕСМЛ).
Загрузка: 10000₈, 2 листа (modloc.txt: авмл 0005).
УПОТР АВМЛ(М7) — рабочий регистр М7.

### 3.2. ВХОДНЫЕ ДАННЫЕ
М1 — номер МГ (физич.), М2 — индекс направления,
М5 — к��д ошибки (0–17), М6 — номер направления,
М10 — адрес возврата (для СТРАСП), М14 — номер заказа.

### 3.3. ЛОГИКА ВХОДА (avml.be:28-75)
1. М5=7 (НЕ ОКОНЧЕН ОБМЕН) → СИНЕН.
2. Иначе: маска D56753 → D56754 (диагностика).
3. ШОЧМГ-24(М1): НЕД 0 → М10 = номер заказа.
4. ОЧЛИС-1(М10): СЛЦ Е20 (счётчик ошибок).
5. 3-е слово бит 5 (ПР5): 0 → G56015; далее бит 26
   (второй сбой) → G56017 или СОШ (снятие заказа).
6. Бит 40 в ТЗНМЛ-24 — «СМЕНИ МГ»: формирование
   сообщения ТСММГ+1 (маска КР1), вывод через НАТ.
7. СОШ: таблица переходов ВХОД1 по коду М5.
