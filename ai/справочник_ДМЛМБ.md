# СПРАВОЧНИК МОДУЛЯ ДМЛМБ (зона 0620)

ИСТОЧНИК: dmlmb.be (2884 строки). СТАРТ '64000'.
Обслуживание магнитных лент (МЛ) и магнитных
барабанов (МБ).

## 1. НАЧАЛЬНАЯ ИНИЦИАЛИЗАЦИЯ (шапка dmlmb.be:14-30)
При запуске без параметров — полный дамп 0-37
листов ОЗУ на 0-37 тракты МБ №23.
ВХОД: ТР5 — номер МБ (если не 0 — особый режим),
ТР6 — доп. параметры.
ИСПОЛЬЗУЕТ: М1 счётчик слов/трактов, М2 счётчик
задержки, М3 номер направления МБ (2), М10-М17
сохраняются. УИА '2003' — блокировка прерываний;
сохранение контекста: СЧИ М1 -> ячейка 9; цикл
копирования 62..72 -> 72..82 (имитация дампа).
Если МБ не 23: ТР5 = N МБ, ТР6 = NN.
