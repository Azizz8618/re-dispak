# СПРАВОЧНИК МОДУЛЯ КОНФУС (КАДОПАМ)

ИСТОЧНИК: konfus.be (1062 строк). Загрузчик и
хозяйство КАДОПАМ; загружает СВЯЗЬ7. ГЕНС/ГЕНС1/
ГЕНС2 — генератор ОС на этапе загрузки; КОНФУС
относится к этапу настройки конфигурации К-71.

## 1. НАЗНАЧЕНИЕ
Настройка модулей ОС для конфигурации К-71,
векторы ПРП, автозагрузка головы СВЯЗЬ7,
параметры нерезидентов (НОМБОБ, ПЕЧАТЬ, РОБОТ,
СОСТАВ, ЭКО и др.).

## 2. АВТОЗАГРУЗКА СВЯЗЬ7 (уточнено 2026-09-05)
Метка загруз (konfus.be:870): сброс шкраб7;
снятие E24 из ШКСВН; настройка ивсв7 (М33=адрес
ИПЗ, М27=УПОК/ИВ25 по биту 15 МГРП); установка
E24 в ШГ; запись аивсв7 в ТУС-1+'31' (диспетчерная
строка Е24-СВЯЗЬ7, disp70.be:614) -> планировщик
(БПУ) подкачивает ИПЗ СВЯЗЬ7.
Локальная метка завоб1 соответствует туссв7
в konfus.be.
Условие входа: непогашенный флаг бита 6 ПРП после
опроса РКС (рабнст & р6прп ≠ 0).

## 3. СВЯДКС (konfus.be:940-985)
ПРП6 -> ОБВНП3 (векторы подменены в нстдкс,
konfus.be:903). кк 26,'0' — чтение РКС (команда
032); флаги направлений -> рабнст; новые биты ->
УСТПРП (МПРП 6/12); при активном бите 6 —
ГАШПРП, СМ=E46, пб загруз.

## 6. СВЯЗЬ С ЭМУЛЯТОРОМ
РКС по 032-чтению должен содержать биты готовности
направления 0 при выставленном ПРП6; контроль —
запись МПРП (cmd_033) и E24 в ШГ
(BESM6/AGENTS.md).

## 7. ОПЕРАТОРСКАЯ ПРОВЕРКА ШКАЛ (на работающей машине)

Команда **АДР NNNNN** в ОС ДИСПАК — просмотр содержимого
ячейки/шкалы по адресу NNNNN. Используется для проверки
состояния шкал (ШКСВН, ШГ, ПРП/МПРП) на живой системе.

Для проверки готовности автозагрузки СВЯЗЬ7:
- ШКСВН: бит E24 должен быть установлен (иначе загруз
  выйдет по `по (М15)`, konfus.be:893-895);
- ШГ: бит E24 (после срабатывания загруз).
- Шкала ШКСВН адресуется по метке в disp70.be:197;
  адрес ячейки смотреть по листингу/загрузке.

## 8. ПОЛНАЯ ЦЕПОЧКА ЗАГРУЗКИ СВЯЗЬ7 (2026-09-17)

Полный путь от вызова планировщика до работы СВЯЗЬ7:

### Шаг 1: НОМБОБ → КОНФУС
НОМБОБ (диасм7, nombob.be:322-325) при рсвсм1==0
выполняет `пб нстдкс` — переход в КОНФУС.

Условие: АПУ (&К71).ДА — конфигурация К-71.
До этого: АС76 (nombob.be:402) — обработка АС
с проверкой табло и УВВ '147'.

### Шаг 2: КОНФУС.нстдкс (konfus.be:930-951)
1. `сч базсв7` — проверка: СВЯЗЬ7 уже загружен?
2. Если да → `пб свядкс` (основной цикл)
3. Если нет:
   - `пв ТБУФ(М15)` — запрос страницы ОЗУ
   - `сда 64-8` — выделение номера листа → `базсв7`
   - `сда 64-2` + `или КУССВ7` + `слц НОММЛ1`
   - `пв ФИЗОБМ(М16)` — чтение СВЯЗЬ7 с МЛ
   - Блокировка прерываний: `уиа '2003'`
   - Запрет приписки: `рег '101'`
   - Сохранение базы: `бсв7мб` = `базсв7`

### Шаг 3: Копирование векторов — нсдкс1
Цикл из 4 итераций (konfus.be:946-951):
- Читает из таблиц `уходы-СВЯЗЬ7` и `адреса-СВЯЗЬ7`
- Записывает в `ОБВНП3` (disp70.be:1572+)
- Подменяет заглушки `пб БМВ` на реальные обработчики
- Доступные векторы: ПРП5-8 и ПРП12

### Шаг 4: свядкс (konfus.be:961-1007)
Основной цикл обработки прерываний ДКС:
- `сч слркс0` + `кк 26,'0'` — чтение РКС (032₈)
- Анализ флагов готовности направлений
- Новые биты → УСТПРП (МПРП 6/12)
- При бите 6 → ГАШПРП, `пб загруз`

### Шаг 5: загруз (konfus.be:887-917)
Настройка планировщика для запуска СВЯЗЬ7:
1. `шкраб7` — сброс шкалы повторной загрузки
2. Проверка E24 в ШГ (если есть → выход)
3. Проверка E24 в ШКСВН (если нет → выход)
4. `нтж ШКСВН` — снятие E24 из ШКСВН
5. Настройка `ивсв7`: М33=базсв7, М27=УПОК/ИВ25
6. `ТУС-1+'31'` = `А(ивсв7)` — диспетчерная строка E24
7. `или E24` в `ШГ` → планировщик (БПУ) подкачивает ИПЗ

### Шаг 6: Возврат в НОМБОБ
Контроль возврата: `НЕЗАВИ` (nombob.be:348)
— цикл по 48 терминалам (ЗВ1-ЗВ1А),
будильники ВППС, ШЗПРИМ, ШБУДИЛ, ШКОРАБ.

## 9. ВЕРИФИКАЦИЯ ЭМУЛЯТОРА (тесты)

Для проверки корректности эмуляции КАДОПАМ-КРК
используются два теста (каталог testdks/):

- **test_k71.txt** — проверка обмена прерываниями
  БЭСМ-6 ↔ ДКС. Валидирует: команды 132/032,
  регистры РСС/РБП/РПР, буферы 000100+, два
  режима обмена. Программа-загрузчик 02036-02067.

- **test_sis_k71.txt** — тестирование ОЗУ ДКС
  с БЭСМ-6 через КАДОПАМ. Валидирует: память
  10–67777₈, команды МАДЛЕН Z13/Z03 (=132/032),
  7 подтестов (единицы, нули, бегущая 1/0 и др.).

### Примечание по командам 132/032
Команды 132 и 032 НЕ входят в стандартный
набор команд БЭСМ-6. Они придуманы специально
для обмена через КАДОПАМ (расширение К-71).
В МАДЛЕН они записываются как Z13 и Z03.
