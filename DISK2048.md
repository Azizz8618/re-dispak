# Диск 2048 - Pascal Runtime Library Source

## Дата: 25.10.2026

### Описание

Диск 2048 используется как источник runtime библиотек для Pascal компилятора.

### Структура зон

| Зона | Содержимое |
|------|-------------|
| 1000-1077 | LIBRA - основные библиотеки |
| 1700-1763 | Runtime процедуры (P/WI, P/WL, P/SYS и др.) |
| 2000 | Pascal Compiler (источник для PERSO) |

### Использование

```bash
# Копирование runtime в зону 2300 на диск 2348
besmtool write 2348 --start=02300 --from-disk=2048 --from-start=01700 --length=0100
```

### Runtime процедуры (зоны 1700)

- P/WI - write(integer)
- P/WL - writeln
- P/WO - write(octal)
- P/RD - read
- P/RI - read integer
- P/SYS - system functions
- P/CA - check address
- P/CE - call trace exit
- И многие другие (см. library.txt в pascal-re)

### Источник

- pascal-re: https://github.com/besm6/pascal-re
- Содержит исходный код компилятора Pascal-Monitor
