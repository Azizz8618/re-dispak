*
АЛГОРИТМ (режим 2):
  1. ДКС записывает 9 слов в РБП
  2. ДКС записывает слово 0777 в ячейку 000100
  3. ДКС считывает РПР (032-чтение)
  4. Сравнивает РПР с записанным словом
  5. Результат выводится на экран оператора

## 7. АППАРАТНЫЙ УРОВЕНЬ ОБМЕНА (test_k71.txt)

Связь БЭСМ-6 ↔ ДКС на аппаратном уровне
описана в testdks/test_k71.txt (НИТИ, 2005/2024).

### Регистры ДКС (сторона Э-60)
| Регистр | Адрес    | Назначение                           |
|---------|----------|--------------------------------------|
| РСС     | 177100   | Слово состояния КАДОПАМ             |
| РБП     | 177000   | Регистр буфера прерываний (9 слов)  |
| РПР     | 032-чт.  | Регистр приёма прерываний (сравн.)  |

### Адреса буферов
| Диапазон     | Сторона  | Назначение                        |
|--------------|----------|-----------------------------------|
| 000100-0120  | ДКС      | Слова прерывания (перехв.прерыв.) |
| 000040-0050  | БЭСМ-6   | Резервные ячейки формы обмена    |

### Два режима обмена
- **Режим 1**: ДКС пишет 1 слово в ОЗУ БЭСМ-6,
  без прерывания. Результат — программная проверка.
- **Режим 2**: ДКС пишет 9 слов в буфер РБП,
  генерирует прерывание. ОС читает через ПРП.

### Программа-загрузчик (ячейки 02036-02067)
Загружает программу в ОЗУ ДКС через 132-запись
(последовательно переписывает 16 слов начиная
с адреса 000100 ОЗУ ДКС).

### Связь с эмулятором (simh)
В besm6_cpu.c: read_032(addr=0) возвращает
krk_status|rks_slr|krk_counter — слово РКС,
формируемое rks_count_interrupt(). Тест проверяет
запись через 132 → чтение через 032 →
сравнение с эталоном.
```

## 8. ТЕСТИРОВАНИЕ ОЗУ ДКС С БЭСМ-6 (test_sis_k71.txt)

Тест выполняется на БЭСМ-6 в автокоде МАДЛЕН
и обращается к ОЗУ ДКС через КАДОПАМ.
Команды 132/032 (МАДЛЕН Z13/Z03) — не входят
в стандартный набор команд БЭСМ-6, придуманы
специально для обмена через КАДОПАМ (К-71).
Источник: testdks/test_sis_k71.txt.

### Диапазон проверяемой памяти
10 — 67777 (ячейки ОЗУ Э-60).

### Подтесты
| №  | Тест          | Проверяемое                          |
|----|---------------|--------------------------------------|
| 1  | Границы       | Запись/чтение по первому и           |
|    |               | последнему адресу                    |
| 2  | Адрес         | Перебор всех адресов, запись         |
|    |               | номера адреса                        |
| 3  | Единицы       | Запись всех 1, проверка              |
| 4  | Нули          | Запись всех 0, проверка              |
| 5  | Бегущая 1     | Сдвиг 16-разрядной единицы           |
| 6  | Бегущий 0     | Сдвиг 16-разрядного нуля             |
| 7  | Произвольный   | Константа 113351                    |

### Команды БЭСМ-6 в автокоде МАДЛЕН
Тест написан на МАДЛЕН (автокод БЭСМ-6),
выполняется на стороне БЭСМ-6 и обращается
к ОЗУ ДКС через КАДОПАМ.

| Команда МАДЛЕН | Код     | Назначение                         |
|----------------|--------|------------------------------------|
| Z13,адрес      | 132*   | Запись в ОЗУ ДКС через КАДОПАМ    |
| Z03,адрес      | 032*   | Чтение из ОЗУ ДКС через КАДОПАМ   |

* Команды 132/032 НЕ входят в стандартный
  набор команд БЭСМ-6. Они придуманы
  специально для обмена через КАДОПАМ
  (расширение аппаратурой К-71).

В обеих командах читается нулевой адрес
КАДОПАМ (обращение к адресу 0).

Примеры из теста (стр.102-103, 116):
  2, Z13 ,20000B   — запись в КАДОПАМ (команда 132)
  2, Z03 ,20000B   — чтение из КАДОПАМ (команда 032)

Суффикс B обозначает восьмеричную систему.
Число перед запятой (2) — номер ИР-модификатора.

### Управление через тумблерные регистры
- Направление КРК (0 или 1) — РКС-регистр
- Режим (номер подтеста) — 5 младших разрядов
- Границы (нач./кон. адрес) — 15 разрядов

### Важно: язык теста
Тест test_sis_k71.txt написан НА СТОРОНЕ
БЭСМ-6 в автокоде МАДЛЕН (а не на Э-60).
Команды Z13/Z03 — это мнемоники БЭСМ-6
для записи/чтения ОЗУ ДКС через КАДОПАМ,
аналогичные командам 132/032 в объектном коде.

### Значение для проекта
Тест доказывает, что ОЗУ ДКС доступно для
полноценного тестирования с БЭСМ-6 через
нестандартные команды КАДОПАМ (132/032,
МАДЛЕН Z13/Z03). Диапазон 10–67777 уточняет
заявленный в rukdks.be (стр.150) "00000–77777".
```

## 6. Связанный проект simh (BESM6/AGENTS.md)

### Наблюдение
Код эмулятора besm6_cpu.c (стр.960-1111)
уже реализует основу из test_k71.txt:
- rks_count_interrupt() формирует rks_slr
  с битами 04000/00040/00100/00200/00020
- read_032(addr=0) возвращает
  krk_status|rks_slr|krk_counter
- write_032(addr=077777) генерирует
  PRP_DKS_SREQ + rks_count_interrupt()

### Несоответствие
Тест test_k71.txt ожидает, что запись в ячейку
000100 ОЗУ ДКС вызовет прерывание в БЭСМ-6,
которое БЭСМ-6 прочитает по 032 из ячейки 000100
ОЗУ БЭСМ-6. В текущем эмуляторе:
- write_032(addr=000100) просто записывает
  в kadopam_mem[000100] без генерации прерывания
- read_032(addr=000100) читает kadopam_mem[000100]

Это корректно для штатного режима (ОС сама
управляет обменом), но тест проверяет именно
аппаратный механизм перехватчика прерываний,
который в эмуляторе не моделируется.

### Рекомендация
В BESM6/AGENTS.md добавить примечание:
"Тест test_k71.txt требует аппаратной имитации
перехватчика прерываний ДКС. В текущей эмуляции это
не реализовано — модель упрощённая (прямая
запись/чтение kadopam_mem). Полная эмуляция
требует моделирования РСС/РБП/РПР на стороне
Э-60."
